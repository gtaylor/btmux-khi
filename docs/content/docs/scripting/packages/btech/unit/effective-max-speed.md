Returns a live unit's effective maximum speed.

## Function

### Synopsis

```lua
btech.unit.effective_max_speed( unit )
```

### Arguments

`DbRef|Object unit`
: The live unit.

### Returns

`number movement_points`
: The effective maximum speed in movement points.

Use `effective_max_speed_kph` when kilometers per hour are required.
